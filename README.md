# XScavenger for GFOS

The AmiCradle Team's port of SDL Scavenger (David Ashley's Lode
Runner-style platform game, SDL version by Barry Mead) to GFOS: AmigaOS
3.2 with GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2. It ships as a
release archive with an Installer and as the GFOpenUp part
Parts/XScavenger.

Upstream is fetched at build time (package/xscavenger.lock); this
repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
